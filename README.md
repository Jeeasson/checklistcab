# Checklist Matrícula Permanente CDAP

PWA moderna para controlar requisitos de inscripción al Colegio Departamental de Arquitectos de Potosí.

## Características

- Progressive Web App (PWA)
- Funciona offline
- Guarda avance en LocalStorage
- Barra de progreso
- Responsive
- Lista de requisitos editable en app.js

## GitHub Pages

1. Subir el contenido del repositorio.
2. Settings → Pages.
3. Deploy from branch.
4. Branch: main / root.
5. Abrir la URL generada.
